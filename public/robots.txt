# Migracijski atlas županija — https://migracijski-atlas.hr/
#
# Everything here is one page. State lives in the URL fragment (#v=…&y=…),
# which is never sent to a server and never crawled, so there is nothing to
# disallow: the whole site is the one document below.
#
# Every crawler and bot is allowed, deliberately and without exception: search
# engines, archivers, academic crawlers, and AI/dataset crawlers (GPTBot,
# ClaudeBot, CCBot, Google-Extended, Applebot-Extended and the rest) alike.
# There are no per-agent blocks below, and none should be added without meaning
# to: a `User-agent: <name>` group *replaces* the `*` group for that agent, so
# one narrow block silently exempts that crawler from the Allow here.
#
# In particular /assets/ stays crawlable — the page is rendered to be indexed,
# and a robots.txt that hides the CSS and JS of a JavaScript-rendered atlas
# hides the atlas.
#
# This file has to exist as a *file*: vercel.json rewrites /(.*) to
# /index.html, so without it this path answered with the app's HTML and a
# crawler parsing <!DOCTYPE html> as directives got 31 syntax errors
# (measured — Lighthouse SEO, "robots.txt is not valid"). Static files are
# matched before rewrites, so the file alone is the fix.

User-agent: *
Allow: /

# Absolute by protocol — a Sitemap URL may not be relative. Safe to hardcode:
# robots.txt is only ever fetched from an origin root, and the build is
# `base: '/'` anyway (see vite.config.ts — the subpath property was retired
# because relative asset URLs and the catch-all rewrite cannot both hold).
Sitemap: https://migracijski-atlas.hr/sitemap.xml
